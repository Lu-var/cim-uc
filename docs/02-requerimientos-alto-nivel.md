# 02 · Requerimientos de alto nivel

| RA | Problema que resuelve |
|---|---|
| **RA-01** La aplicación deberá permitir explorar proyectos, capacidades I+D, integrantes, publicaciones y actividades de CIM UC. | La información de CIM UC es abundante y dispersa, y desde el celular no hay una forma simple de recorrerla. |
| **RA-02** La aplicación deberá permitir buscar contenidos escribiendo texto. | Quien busca algo puntual no tiene cómo encontrarlo rápido entre tantos contenidos. |
| **RA-03** La aplicación deberá permitir filtrar contenidos por tipo, área temática y año. | Personas con intereses muy distintos necesitan acotar los resultados a lo que realmente les sirve. |
| **RA-04** La aplicación deberá permitir ver el detalle de un contenido. | Un listado no basta para evaluar si un proyecto, capacidad o publicación responde al interés de la persona. |
| **RA-05** La aplicación deberá permitir ver cómo se relacionan los contenidos, por ejemplo los integrantes, capacidades y publicaciones de un proyecto. | Los contenidos aparecen aislados y la persona no ve con qué otras cosas se conectan. |
| **RA-06** La aplicación deberá permitir encontrar actividades y oportunidades de colaboración según lo que le interese a la persona. | Investigadores y empresas no identifican fácilmente dónde y cómo pueden colaborar con CIM UC. |
| **RA-07** La aplicación deberá permitir enviar una solicitud de contacto simulada a CIM UC y ver una confirmación. | Tras encontrar algo pertinente, la persona no tiene un camino claro para acercarse a CIM UC. |
